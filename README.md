# Pfad

Schulinterne Web-App zur alltagsnahen Verhaltensbeobachtung im Gemeinsamen Lernen.

- Läuft komplett im Browser (iPad, Handy, PC), auch offline.
- Förderdaten bleiben auf dem Gerät. Dieses Repository enthält nur den App-Code, keine Daten.
- Austausch im Team optional über verschlüsselte Dateien mit ausgewählten Kindern. Später ggf. ein Schulserver im Schulnetz.

Installation auf iPad/iPhone: Adresse in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
Schritt-für-Schritt-Anleitung für iPad, iPhone und Android: https://hbg-pfad.github.io/pfad/einrichten.html

Prototyp. Einsatz mit echten Fällen erst nach Freigabe durch Schulleitung und Datenschutzbeauftragte:n.

## Beta
Neue Versionen erscheinen zuerst unter https://hbg-pfad.github.io/pfad/beta/ („Pfad Beta“, gelbes BETA-Schild).
Die Beta speichert getrennt von der Hauptversion (eigener Speicherschlüssel, eigener Offline-Zwischenspeicher).
Die Hauptversion unter /pfad/ wird erst nach ausdrücklicher Freigabe aktualisiert.
